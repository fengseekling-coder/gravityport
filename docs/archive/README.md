# Historical Design References

Files in this directory are retained only as historical design references. They date from before the product was renamed from MOSA to GravityPort and do not describe the current GravityPort interface, product version, release status, or supported behavior.

Use the live application and the current documents linked from the repository root `README.md` as the source of truth. Historical prototypes may contain placeholder data, obsolete version labels, interactions that were later redesigned, and visual treatments that are no longer implemented.

`MOSA_UI_Integrated_R20.html` is the archived R20 integrated UI prototype. It is intentionally kept out of the active `docs/` level so it cannot be mistaken for current product documentation.
