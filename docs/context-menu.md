# 右键菜单功能说明

本文档按当前 GravityPort 界面的右键菜单现状编写，与界面文字一一对应。菜单按所在位置分成六类：单张素材、多选、堆叠、空白处、回收站、侧栏分组。

## 单张素材

在画廊中的一张素材卡片上右键点击，菜单从上到下是：

- **在查看器中打开** - 进入大图查看模式
- **在素材库中显示** - 退出当前预览/堆叠、清空搜索并回到「所有素材」，检视器定位到这张素材
- **复制图片** - 把素材库中保存的原图复制到系统剪贴板
- **剪切** - 剪切这张素材，等待粘贴到堆叠（⌘X / Ctrl+X）
- **复制提示词** - 复制已记录的 Prompt；没有记录时不编造
- **复制路径** - 复制素材在素材库中的托管路径
- **收藏 / 取消收藏** - 单个切换项，按当前状态显示
- **添加分组** - 子菜单列出「新建分组并移入」和全部现有分组（带分组颜色圆点）
- **移除分组** - 把素材移出当前分组；未分组时置灰
- **导出至** - 把原图文件下载到浏览器下载位置
- **堆叠内额外项：移出堆叠** - 在堆叠成员视图里右键卡片时出现
- **移至回收站** - 危险操作，默认弹确认框（可勾选「不再提醒」）；素材在回收站保留 90 天

## 多选

选中多张卡片（框选、Shift 加选、⌘A 或逐张 ⌘ 点）后右键，菜单标题显示「已选 {count} 项」，条目作用于整个选区：

- **剪切** - 剪切全部所选；选区里含堆叠时置灰
- **收藏 / 取消收藏**、**添加分组**（子菜单）、**移除分组**
- **导出至** - 选区里含堆叠时这一节整体不出现
- **堆叠所选** - 根画廊里把所选素材合成一个堆叠；选区含堆叠时不可用
- **堆叠内额外项：移出堆叠** - 在堆叠成员视图里对多选生效
- **移至回收站** - 批量移入回收站；完成提示显示成功/失败数量，可撤销

多选菜单不再显示「在查看器中打开」「复制图片」「复制提示词」「复制路径」这类单张条目。

## 堆叠

画廊中的堆叠封面卡上右键点击：

- **粘贴到此堆叠** - 只有正在剪切（⌘X 之后）时出现
- **打开堆叠** - 进入堆叠成员视图
- **添加分组**（子菜单）/ **移除分组** - 整个堆叠归组或出组
- **重命名堆叠** - 设置显示名称
- **解散堆叠** - 确认后只解除堆叠关系，成员恢复为独立素材，不删除、不归档
- **移至回收站** - 危险操作；确认框显示成员数量，成员素材一起进入回收站，之后从回收站恢复时堆叠关系与手动顺序自动重建

## 空白处

**画廊空白处**（所有素材、分组、待整理、收藏等视图的网格空白）右键：

- **粘贴** - 只有正在剪切时出现；把剪切的素材移出原来的堆叠，恢复为独立素材
- **新建分组**
- **全选**（⌘A / Ctrl+A；库为空时置灰）
- **刷新素材库**

**堆叠成员视图空白处**右键：

- **返回素材库**
- **粘贴** - 只有正在剪切时出现；把剪切的素材移入当前堆叠
- **重命名堆叠** / **解散堆叠**
- **全选** / **刷新**

## 回收站

回收站有独立菜单。回收站里堆叠封面不再有自己的菜单。

**回收站内单张卡片**右键：

- **在查看器中打开** / **复制路径**
- **恢复** - 回到正常素材库，保留可恢复的分组、堆叠、版本和生成历史关系
- **永久删除** - 危险操作，确认后立即删除素材及其托管文件，不可恢复

**回收站内多选**右键（标题「已选 {count} 项」）：复制路径、**恢复 {count} 个素材**、**永久删除 {count} 个素材**。

**回收站空白处**右键：

- **全选**
- **清空回收站** - 危险操作，确认后清空；回收站为空时置灰

回收站中的素材从进入时刻起独立计算 90 天保留期，到期自动永久删除；卡片上显示剩余天数倒计时。普通删除后的 6 秒内，提示条上有「撤销」按钮。

## 侧栏分组

在侧栏「我的分组」的一个分组名上右键点击（「智能分组」按来源自动生成，没有此菜单）：

- **重命名分组**
- **上移分组** / **下移分组** - 调整分组在侧栏中的顺序
- **分组颜色** - 六色色板，选中即标记到分组
- **分组统计** - 显示素材总数、版本条目、回收站中、按分类和按来源的统计
- **导出分组** - 导出该分组当前素材的 JSON 清单与元数据。导出文件只含元数据（文件名、提示词、标签、分组、分类、评分、业务字段、来源类型、时间戳等），不包含本机路径与目录、只有本机服务能解析的 `/library/...` 链接和采集时记录的网页/媒体链接（`page_url`、`source_media_url` 等），可以安全分享。删除只看字段名：业务字段里键名以 `_path`、`_url`、`_dir` 结尾或叫 `path` 的项同样不会导出，其余业务字段原样保留
- **合并分组** - 把当前分组的素材并入另一个分组并删除当前分组（还有其他分组时才显示）
- **删除分组** - 只有一个确认框：「仅删除分组，保留其中全部素材。」素材回到未分组，不会进入回收站

## 交互设计特性

### 视觉与键盘

- 菜单跟随浅色/深色主题，使用当前 GravityPort 界面的设计令牌。
- **方向键上/下** 在菜单项间移动，**方向键右/左** 进入或退出子菜单，**Enter** 执行，**Escape** 关闭。
- 菜单自动避开屏幕边缘；子菜单优先向右展开，空间不足时向左。
- 禁用项显示为灰色；不可逆操作（永久删除、清空回收站、移至回收站）使用危险样式。普通删除先进入回收站并可撤销，只有永久删除和清空回收站不可恢复。

## 技术实现

- `web/gravityport/src/context-menus.ts` 是纯逻辑模块，不依赖 React 或 DOM：`buildContextMenu(ctx)` 按目标（asset / stack / stack-blank / gallery-blank）、范围（普通 / 回收站）、选中数量、是否含堆叠、是否在堆叠内、剪切状态和分组列表返回菜单条目。条目文字即界面上的中文原文，多选标题保留 `{count}` 占位符由界面填充，分组条目携带颜色供圆点渲染。
- `web/gravityport/src/App.tsx` 负责菜单的显示与分发：收集上下文、渲染条目与子菜单、按条目 id 执行动作（API 调用、确认框、Toast 提示），并实现侧栏分组管理菜单与分组管理对话框。
- 界面文字的中英文对照在 `web/gravityport/src/i18n.ts`。

### API 集成

所有菜单操作通过现有的 GravityPort API 实现：

- `/api/assets/:projectId/:assetId` - 更新素材
- `/api/assets/:projectId/:assetId/restore` - 从回收站还原素材
- `/api/assets/:projectId/:assetId/permanent` - 永久删除回收站素材
- `DELETE /api/trash` - 通过请求体中的 `projectId` 清空指定项目的回收站
- `/api/asset-stacks/:stackId` - 读取、重命名（PATCH）或解散堆叠，并配合成员接口维护堆叠内容与顺序
- `/api/asset-stacks/move` - 在堆叠之间批量搬移素材
- `/api/groups` - 管理分组
- `/api/group-order` - 调整分组顺序
- `/api/groups/:name/merge` - 将当前分组成员并入另一个分组
- `/api/open-folder` - 在系统文件管理器中打开受信任的库/来源目录

## 支持范围

这份文档只描述当前仓库已经实现并受测试覆盖的右键菜单行为。GravityPort Desktop 的 Electron 界面是主要支持面；源码 Web 界面复用同一套菜单模块，仓库不为个别浏览器维护独立兼容矩阵。

未来功能和尚未实现的菜单想法应放到 GitHub Issues / Discussions，而不是混入当前功能说明。
