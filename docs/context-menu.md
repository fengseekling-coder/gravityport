# 右键菜单功能说明

GravityPort 现已支持完整的右键菜单功能，为导航栏和素材库提供快捷操作入口。

## 功能概览

### 🧭 导航栏右键菜单

在侧边栏的**分组（Groups）**上右键点击，可以：

- **上移 / 下移分组** - 调整分组在侧边栏中的顺序
- **重命名分组** - 直接在侧边栏内修改分组名称
- **合并到其他分组** - 将当前分组中的素材移动到目标分组，并删除当前分组
- **导出分组** - 导出该分组当前素材的 JSON 清单与元数据。导出文件只含元数据（文件名、提示词、标签、分组、分类、评分、业务字段、来源类型、时间戳等），不包含本机路径与目录（素材原图、导入源、Cowart 项目/画布目录等）、只有本机服务能解析的 `/library/...` 链接和采集时记录的网页/媒体链接（`page_url`、`source_media_url` 等），可以安全分享。删除只看字段名：业务字段里键名以 `_path`、`_url`、`_dir` 结尾或叫 `path` 的项同样不会导出，其余业务字段原样保留
- **分组统计** - 查看该分组的素材数量
- **删除分组** - 先确认删除分组，再选择“保留素材”或“移到回收站”。保留时素材回到未分组；选择移到回收站时，分组删除，素材进入回收站并保留 90 天

### 🎨 素材卡片右键菜单

在素材卡片上右键点击，可以：

#### 基础操作
- **在查看器中打开** - 进入专用大图查看模式
- **在 Finder / 文件资源管理器中显示** - 通过桌面平台能力定位到原始文件
- **复制路径** - 复制文件的绝对路径
- **复制图片** - 将素材库中保存的原图直接复制到系统剪贴板

#### 素材管理
- **添加到收藏 / 取消收藏** - 快速切换收藏状态
- **移动到分组** - 快速移动到其他分组（带子菜单）
- **查看版本历史** - 打开检视器查看版本树

#### 创作相关
- **复制提示词** - 复制生成时使用的 Prompt

#### 导出与删除
- **导出素材** - 导出单个素材及其元数据
- **移到回收站** - 从正常素材库隐藏并进入回收站。每个素材从进入回收站的时间开始独立计算 90 天保留期

#### 回收站
- **还原** - 将素材恢复到正常素材库，并保留其可恢复的分组、堆叠、版本和生成历史关系
- **永久删除** - 立即彻底删除回收站中的素材及其托管文件，此操作不可撤销
- **自动清理** - 素材进入回收站满 90 天后自动永久删除；不同素材按各自的删除时间独立计时

#### Stack 节点
- **打开 Stack** - 进入该 Stack 的成员视图
- **重命名 Stack** - 为 Stack 设置显示名称；空名称不会被保存，刷新后名称保持
- **解散 Stack** - 仅解除 Stack 关系，不删除、归档或移动成员素材；确认后 Toast 会显示恢复为独立素材的数量
- **移到回收站** - 危险操作。确认框显示 Stack 内素材数量。数据层语义：进入回收站的是 Stack 的全部活跃成员素材（复用普通素材的回收逻辑）；`asset_stacks` 记录与成员关系**原样保留**——Stack 本身没有独立的"已删除"状态，它从画廊消失只是因为活跃成员数为 0。从回收站还原成员后，Stack 关系与手动顺序自动重建

### 📋 空白区域右键菜单

在素材网格的空白处右键点击，可以：

- **创建分组** - 打开新建分组界面
- **从剪贴板粘贴** - 把剪贴板里的图片直接导入到当前分组或 Stack，不再弹出导入对话框
- **刷新素材库** - 重新加载素材列表
- **全选** - 选中所有素材

## 交互设计特性

### 视觉风格
- 跟随系统主题（浅色/深色模式）
- 使用 GravityPort V2 设计令牌
- 圆角卡片风格（12px 圆角）
- 浮动阴影效果

### 键盘导航
- **方向键上/下** - 在菜单项间移动
- **方向键右** - 打开子菜单
- **方向键左** - 关闭子菜单返回父菜单
- **Enter** - 执行当前菜单项
- **Escape** - 关闭菜单

### 智能定位
- 自动检测屏幕边缘，避免溢出
- 子菜单优先向右展开，空间不足时向左
- 垂直方向自动调整位置

### 状态反馈
- 禁用项显示为灰色
- 永久删除等不可逆操作使用危险样式；普通删除先进入回收站
- 操作完成后显示 Toast 通知
- 危险操作需要确认；普通删除先进入回收站，只有永久删除不可撤销

## 技术实现

### 文件结构
```
app/
├── context-menu.mjs           # 通用右键菜单组件
├── context-menu-actions.mjs   # 菜单项定义和动作处理
├── app.mjs                     # 主应用集成
├── styles.css                  # 右键菜单样式
└── i18n.mjs                    # 国际化文本
```

### 核心模块

#### `context-menu.mjs`
- 创建和显示右键菜单
- 处理键盘导航
- 智能定位和边界检测
- 子菜单支持

#### `context-menu-actions.mjs`
- 定义所有菜单项
- 处理菜单动作
- 集成 API 调用
- 错误处理和反馈

### API 集成
所有菜单操作通过现有的 GravityPort API 实现：
- `/api/assets/:projectId/:assetId` - 更新素材
- `/api/assets/:projectId/:assetId/restore` - 从回收站还原素材
- `/api/assets/:projectId/:assetId/permanent` - 永久删除回收站素材
- `DELETE /api/trash` - 通过请求体中的 `projectId` 清空指定项目的回收站
- `/api/asset-stacks/:stackId` - 读取、重命名（PATCH）或解散 Stack，并配合成员接口维护 Stack 内容与顺序
- `/api/groups` - 管理分组
- `/api/group-order` - 调整分组顺序
- `/api/groups/:name/merge` - 将当前分组成员并入另一个分组
- `/api/open-folder` - 打开文件夹

### 国际化支持
完整的中英文双语支持：
- 简体中文（zh）
- 英文（en）

## 使用示例

### 快速收藏素材
1. 在素材卡片上右键点击
2. 选择"添加到收藏"
3. Toast 提示"已添加到收藏"

### 批量移动到分组
1. 在素材卡片上右键点击
2. 悬停"移动到分组"打开子菜单
3. 选择目标分组
4. Toast 提示"已移动到分组"

### 删除分组
1. 在侧边栏分组上右键点击
2. 选择"删除分组"
3. 确认对话框中点击"删除"
4. 在第二个确认框中选择"保留素材"或"移到回收站"
5. 选择保留时只删除分组，素材回到未分组；选择移到回收站时，素材仍可在 90 天内恢复

## 支持范围

这份文档只描述当前仓库已经实现并受测试覆盖的右键菜单行为。GravityPort Desktop 的 Electron 界面是主要支持面；源码 Web UI 复用同一菜单模块，但仓库目前没有维护 Chrome、Firefox、Safari 的独立版本兼容矩阵，因此不在这里承诺未经持续验证的浏览器最低版本。

未来功能和尚未实现的菜单想法应放到 GitHub Issues / Discussions，而不是混入当前功能说明。
