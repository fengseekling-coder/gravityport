GravityPort 网页生图采集

本地 AI 素材归档工具，支持 ChatGPT、Gemini、Flow 和 Google AI Studio。

工作流

自动发现生成图，或使用浏览器右键菜单快速保存。

GravityPort Desktop 会自动发现并完成本机配对。下面的地址和 Token 主要用于诊断或源码运行时的高级配置。

开启后，扩展仅在支持的网站中观察与生成媒体相关的页面数据，并把匹配到的媒体、Prompt 与来源发送到本机 GravityPort。默认关闭；不会上传到 GravityPort 云端。

诊断记录

开启后，仅在插件拿到图但没有拿到 Prompt 时，把这一轮看到的流量结构（字段路径、长度、模型名）记录到本机。不会记录任何对话文字、提示词、URL 查询参数、Cookie 或 Token，只用于排查 5.6 / gpt-6 等未能取到提示词的情况。默认关闭。

After enabling, only conversations whose prompt could not be matched are recorded (so the diagnostic ring buffer never sees the prompt itself). Field paths, lengths, and a small allowlist of primitive values only. Default off.
